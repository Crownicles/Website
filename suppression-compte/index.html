Depuis l'application

L'application Crownicles permet de supprimer votre compte sans passer par nous. Le chemin se trouve dans les paramètres, à la rubrique « Supprimer mon compte ».

Un écran récapitule ce qui disparaît et ce qui subsiste, puis demande une confirmation. La suppression est effectuée immédiatement après cette confirmation.

En nous écrivant

Si l'application n'est pas installée, la suppression peut être demandée à contact@crownicles.com, depuis l'adresse électronique rattachée au compte ou en indiquant le nom d'utilisateur concerné.

Un code personnel vous est alors transmis par courrier électronique. Ce code doit être renvoyé au bot Discord en message privé, puis confirmé par une phrase : la suppression n'est déclenchée que par cette confirmation, que nous ne pouvons pas donner à votre place.

Ce qui est supprimé

Le compte et les éléments qui permettent de vous identifier sont effacés : identifiant, adresse électronique, nom d'utilisateur, mot de passe, et le lien éventuel avec un compte Discord.

La connexion devient impossible, que ce soit depuis l'application, depuis Discord ou depuis le site.

Ce qui est conservé

Les données de jeu sont conservées sous une forme anonyme, une fois le compte effacé : plus rien ne permet de les relier à votre personne. Le personnage reste visible dans les classements sous un nom anonyme.

Les textes libres que vous avez saisis, comme les noms donnés aux familiers, le nom d'une guilde et sa description, sont également conservés. Ces éléments servent à l'équilibrage du jeu et à la cohérence des parties des autres joueurs.

La suppression de ces contenus peut être demandée séparément, à la même adresse.

Délais

La suppression effectuée depuis l'application est immédiate et irréversible : la progression ne peut pas être restaurée.

Une demande adressée par courrier électronique est traitée dans un délai d'un mois, conformément au Règlement général sur la protection des données. La suppression devient effective dès que vous confirmez le code reçu.

Nous contacter

Pour toute question relative à la suppression de votre compte, vous pouvez nous écrire à l'adresse suivante :

contact@crownicles.com
